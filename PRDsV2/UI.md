UI 设计规范与页面草图文档：快找房 v2.0 (商业化版)
一、 整体视觉风格与色彩升级
v2.0 面向商业化运行，UI 必须传达出“数据驱动”与“高效管理”的质感。

主色调：科技蓝 (#1890ff)，用于强调核心操作（如添加按钮、ECharts 折线图主色）。

状态反馈色 (核心更新)：


未审核/未通过：醒目的警告橙 (#faad14) 或危险红 (#ff4d4f)，用于高亮显示房源表格中的“审核”按钮，引导管理员进行审核干预 。

已通过/正常：成功绿 (#52c41a)，用于状态标签或数据指标的上升趋势。

图表色板 (ECharts)：建议采用多色渐变（如蓝紫渐变、绿蓝渐变），打破后台系统的沉闷感，提升数据大盘的高级真实感。

二、 全局布局与组件规范
系统维持“左侧菜单 + 顶部标头 + 右侧主体”的经典框架。

1. 顶部标头 (Header)

元素精简：移除 v1.0 中占地过小的天气信息，将其移入首页模块 。


用户交互：右上角保留当前登录用户信息，点击后不再跳转页面，而是直接弹出“用户设置框”，展示：账户名称、姓名、联系方式、角色 。弹窗提供确定与取消按钮 。

2. 首页数据大盘 (Home Dashboard)

天气与数据卡片：增加天气多项信息展示区域，并新增一栏核心业务数据展示：上架房源数量、审核房源数量、房源签订数量、收益金额 。旁边配备“按时间查询统计”按钮 。


图表规范：使用 ECharts 渲染用户活跃度折线图与房屋数量柱状图 。

3. 表格与表单 (Table & Form)

图片缩略图：房源模块的表格中新增“图片”、“房屋位置”、“出租用户名称”列 。建议以 40px * 40px 的圆角方块展示首图，支持点击预览大图。

操作列排版：由于按钮增多，不同角色看到的按钮应有权限隔离。


统一动态表单：使用统一模版处理添加用户、房屋、角色 。房源信息表单需增加一行上传图片入口，支持多张照片 (png/jpg) 。

4. 权限与状态视觉隔离 (RBAC UI)

审核流视觉：房源表格中，只有未审核或审核未通过的数据，其“审核”按钮才处于高亮显示状态；审核一旦通过，该按钮从 UI 上彻底消失 。


角色管理：用户展示列增加角色信息 ，且左侧新增角色模块，展示角色名称、描述及创建时间，右侧提供权限配置按钮 。
